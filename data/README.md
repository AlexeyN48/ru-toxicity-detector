# Данные

Сами данные в git не хранятся (`.gitignore`). В репозитории лежат только этот файл и
[`manifest.json`](manifest.json) — версия датасета, sha256 исходного файла и размеры сплитов.

## Источник

| Поле | Значение |
|---|---|
| Датасет | [Russian Language Toxic Comments](https://www.kaggle.com/datasets/blackmoon/russian-language-toxic-comments) (Kaggle, версия 1, 2019) |
| Тексты | комментарии с 2ch.hk и pikabu.ru |
| Лицензия | GPL-2.0 (по метаданным Kaggle) |
| Исходный файл | `labeled.csv`: колонки `comment` (текст) и `toxic` (0.0 / 1.0) |
| Размер | 14 412 комментариев: 4 826 токсичных, 9 586 нетоксичных |

## Как получить

```bash
python -m toxicity.data prepare   # скачать, очистить, разбить, записать manifest.json
python -m toxicity.augment        # data v2: train + нейтральные фразы для fairness
```

Скачивание идёт по публичной ссылке Kaggle API, аккаунт не нужен.

## Что получается

```
data/
├── raw/labeled.csv          # исходный файл
├── processed/
│   ├── train.csv            # 70 %, стратифицировано по классу, seed 42
│   ├── val.csv              # 15 % — порог, ранняя остановка
│   ├── test.csv             # 15 % — итоговые метрики и fairness
│   └── train_aug.csv        # train + нейтральные фразы с упоминанием групп (data v2)
└── manifest.json
```

Очистка: обрезка пробелов, удаление пустых строк и дубликатов (после обрезки пробелов
нашлось 257 дубликатов, осталось 14 155 комментариев). Регистр, пунктуация, мат и эмодзи
сохраняются: они несут сигнал о токсичности.

## Версии

| Версия | Состав | Где используется |
|---|---|---|
| v1 | очищенный Kaggle-датасет | `ruBert-base`, `rubert-tiny2` |
| v2 | v1 + 360 нейтральных фраз с упоминанием групп ([шаблоны](../configs/augmentation.yaml)) | `ruBert-base-aug` |
